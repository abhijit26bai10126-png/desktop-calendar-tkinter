# 📆 desktop-calender-thinker

A lightweight Python desktop application that displays monthly calendars for any selected year and month using a clean Tkinter graphical user interface.

## Features
- **Dynamic Calendar Display:** Generate accurate calendar layouts for any year between 1947 and 2150.
- **Easy Controls:** Simple Spinbox inputs for selecting years and months.
- **Monospaced Layout:** Properly aligned dates and week headers for optimal readability.
- **Error Handling:** Built-in validation to handle empty or invalid inputs gracefully.

## Built With
- **Python 3**
- **Tkinter:** Standard Python GUI library
- **Calendar Module:** Built-in Python library for calendar operations

## Getting Started

### Prerequisites
Make sure you have Python installed on your system. Tkinter comes pre-installed with standard Python distributions.
